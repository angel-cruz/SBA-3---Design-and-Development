# SBA-3---Design-and-Development
Take a Figma design from Frontend Mentor and implement it using Bootstrap

### Reflection

- **Challenges I encountered during the project:**  
  One challenge I had was working with GitHub branches and making sure I was committing and merging my changes correctly without messing up my main branch.

- **My approach to solving these challenges:**  
  I worked on the project one section at a time and used separate feature branches for different parts of the website. This made it easier to test my changes and fix problems before merging everything together.

- **Improvements I would make if given more time:**  
  If I had more time, I would add JavaScript and DOM manipulation to make the page more interactive for users, such as allowing them to create posts, update content, or interact with the dashboard.
